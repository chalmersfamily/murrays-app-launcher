# Murray’s Launcher 1.0.0

A static launcher for GitHub Pages. Publish the root of the repository. All assets use relative paths so the launcher can run at a GitHub Pages project URL. No build or dependencies are required.

Idea Garden opens at its standalone Cloudflare address. File & Follow Up continues to open on the original Launchpad. Plants in our Yard keeps the existing OneDrive installer directions. Android intents require the corresponding app to be installed. The launcher contains links only and stores no app data. The links remain visible offline after installation, but linked sites require their own network or offline support.
